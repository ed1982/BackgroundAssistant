Model
Voice

Ambient speech is transcribed in memory and never written to disk. Only the exchanges you trigger are stored — your question, the answer, and the context that was sent — in a conversation history you can read and delete at any time. Nothing else you say is kept.

While this is on, everything you say near the machine is written to the log file. It switches itself off after 24 hours.
